# Personal research-pipeline examples

One-off scripts from the original spine-segmentation research workflow.
They encode machine-specific paths, dataset names, and project names —
they will NOT run as-is on your machine. Kept as worked examples of
driving the catalog / label / export APIs from scripts.

For reusable tools see the parent directory (`launch_training.py`,
`import_from_library.py`, `restage_project.py`, ...).
